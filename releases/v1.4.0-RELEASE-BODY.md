### Highlights

- **Reference Model identity:** unified architecture/guide framing across `README.md`, `GETTING-STARTED.md`, `GOVERNANCE.md`, `DESIGN.md`, `SECURITY.md`, `CITATION.cff`, `mkdocs.yml`, and chapters, with `Operational & scope notes` replacing `Author practical guidance`
- **Machine-readable Evidence Pack (`schemas/`):** Draft 2020-12 JSON Schema (`CycloneDX 1.6`/`1.7`, `allOf` conditional constraints for `Managed-API` vs self-hosted/`Agentic-MCP`, strict RFC-3339 date-time, `dataProvenance`, `localRunnerConfig`, `runtimeAgentConfig` `ASI02`/`ASI06`/`MCP`, `runtimeTelemetry`) + `Agentic-MCP` and `Managed-API` examples
- **Executable OPA/Conftest policies (`policies/`):** fail-closed admission rules across `CP4`/`CP7`/`CP8`/`CP9` (`package main`, quantitative `CP7` gates, CycloneDX component hash checks, `MCP09`/SSRF/cleartext/`ASI02`/`ASI06`/`ASI07` `delegationDepthMax`), unit tests (`conftest verify`), and Kubernetes inference Pod/Deployment/Service hardening (`policies/k8s/`, `package mlsecops.k8s`)
- **Zero-dependency static MCP & model scanner (`scripts/ai_security_scan.py` + `tests/`):** ZWNJ-preserving Unicode/Bidi & NFKC homoglyph filtering, MCP poisoning/shadow/SSRF checks, canonical `tools/list` SHA-256 pinning, VM stack+memo `pickletools` disassembly (`CVE-2025-10157`), ZIP polyglots/LFH diffs/CRC-32 checks (`CVE-2025-1945`/`CVE-2025-10156`), bounded GGUF KV walk (`CVE-2024-34359`), ONNX traversal (`CVE-2024-5187`), NumPy `.npy` object pickles, and Safetensors offset integrity
- **Lifecycle & domain expansions:** Vector DB backup/snapshot revocation (Ch.4/Ch.7), Docker Model Runner OCI distribution/local runner guidance (`Ch.5` / `E.1.7` / `Ch.12` / `Ch.16`), `E.4` YAML↔JSON mapping, and Mermaid dark-mode `strict` rendering fixes
- **Release & CI hardening:** SHA-256-verified Conftest (`v0.71.1`), `check-jsonschema`, `scripts/verify_repo.py` single-pass QA verification, `pip-audit` dependency checks, draft-safe `handbook-artifacts.yml` uploads, SHA-256 template verification in `scripts/build-docx.py`, and broader `SHA256SUMS` coverage
