## v1.5.0 — MLSecOps Reference Model & Practical Guide

Elevates **ISO/IEC 27090:2026** as the primary technical AI security baseline, formalizes the machine-verifiable **`MLS-*` Conformance Profile (Levels 1–3)** with clause-level cross-walks (`OWASP AISVS v1.0 C1–C12`, `CSA MAESTRO L1–L7`, `ISO/IEC 42001`, `NIST AI RMF`, `MITRE ATLAS`), adds canonical **`in-toto` Statement v1 + DSSE + Witness + Archivista** provenance patterns, brings distributed **`DDP`/`FSDP`/`RLHF`/`DPO` pretraining clusters (`Appendix E.1.8`)** into scope, and ships the hardened `scripts/ai_security_scan.py` static scanner + deterministic controlled evaluation benchmark (`scripts/eval_benchmark.py`).

### Highlights

- **ISO/IEC 27090:2026 primary standards elevation:** aligns threat/control mapping (`Clauses 5–7`, `Annexes A–C`) across chapters ahead of overlapping OWASP taxonomies while keeping OWASP AI Exchange as an open companion and adding a transparent peer comparison & limitations table in `README.md`
- **`MLS-*` Conformance Profile & Standards Cross-Walks ([`references/STANDARDS-ALIGNMENT.md`](../references/STANDARDS-ALIGNMENT.md)):** Levels 1–3 control IDs verified by JSON Schema + OPA/Conftest Rego, plus clause-level tables for `OWASP AISVS v1.0 (C1–C12)`, `CSA MAESTRO (L1–L7)`, `ISO/IEC 42001`, `NIST AI RMF`, and `MITRE ATLAS`
- **`in-toto` v1, DSSE, Witness & Archivista ([`references/INTOTO-WITNESS-ARCHIVISTA.md`](../references/INTOTO-WITNESS-ARCHIVISTA.md)):** `mlsecops-attestation.v1.schema.json` (`ResourceDescriptor` matched strictly by digest), `dsse-envelope.v1.schema.json`, `--emit-intoto` / `--emit-dsse` CLI, DSSEv1 PAE helper, `policies/witness/mlsecops-witness-policy.json` (Base64 Rego modules), and private Archivista GraphQL storage guidance
- **Distributed Pretraining & Alignment (`Appendix E.1.8`):** `Pretraining-Distributed` scope + `trainingClusterConfig` enforcing collective network isolation, worker attestation, checkpoint digest binding, RLHF/DPO preference provenance, gradient clipping, and SFT-to-DPO validation gates
- **Hardened static scanner, K8s/Rego gates & controlled benchmark ([`references/EVALUATION-BENCHMARK.md`](../references/EVALUATION-BENCHMARK.md)):** Pickle VM stack/memo disassembly (`CVE-2025-10157`), ZIP differential/CRC checks (`CVE-2025-1945`/`CVE-2025-10156`), bounded GGUF KV SSTI (`CVE-2024-34359`), varint ONNX traversal (`CVE-2024-5187`), Unicode/NFKC/SSRF/MCP09 rules, Kubernetes workload hardening (`vLLM` auth, hostPort/LoadBalancer blocking), and reproducible controlled benchmark (`11/11` recall, `0/5` FPR, `7/7` policy accuracy)
